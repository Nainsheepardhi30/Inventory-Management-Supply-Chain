# Inventory Management & Supply Chain
A Python-based Inventory Management Dashboard built using Python, Streamlit, and MySQL to manage products, suppliers, stock levels, and reorder operations.

🚀 Project Overview

This project simplifies inventory and supply chain operations through an interactive dashboard connected to a MySQL database. It helps users monitor inventory, manage product information, view product history, and handle reorder workflows.

🛠️ Tech Stack

Python

Streamlit

MySQL

SQL

✨ Features

Inventory Dashboard: View key inventory and supplier metrics.

Product Management: Add new products and manage product information.

Supplier Management: View supplier contact details.

Stock Monitoring: Track stock quantities and reorder levels.

Reorder Management: Place reorders and process received stock.

Product History: Review product-related inventory records.

SQL Integration: Use SQL queries, joins, views, and stored procedures.
